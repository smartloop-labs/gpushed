Use cases

What people run on a gpushed box.

Anything that needs CUDA and more VRAM than your Mac has. A few of the common ones, with the plan that fits each best:

l4 · a100

Fine-tune open LLMs

LoRA and QLoRA on Llama, Mistral, Qwen or Gemma with PEFT, TRL or Unsloth. A 7B–8B model fits on an L4; reach for the A100 for 13B+ or longer contexts.

$ pip install torch peft trl bitsandbytes
$ python finetune.py
l4

Serve and test models

Stand up vLLM, TGI or Ollama behind an OpenAI-compatible API and test your model before you pick production hosting.

$ pip install vllm
$ vllm serve Qwen/Qwen2.5-7B-Instruct
t4 · l4

Generate images and video

Run Stable Diffusion, SDXL, Flux or ComfyUI workflows with diffusers, train LoRAs on your own style, and batch-render without heating up your laptop.

$ pip install diffusers transformers
$ python sdxl.py
any plan

Write CUDA and Triton kernels

Apple silicon has no CUDA, so write, compile and run real kernels here with nvcc or Triton, on a real NVIDIA GPU.

$ nvcc -O3 matmul.cu -o matmul
$ ./matmul
l4 · a100

Clone the repo, pip install -r requirements.txt, and rerun the experiments. Run lm-eval-harness or your own benchmarks on a clean, known machine.

$ git clone github.com/…/paper-code
$ lm_eval --model hf --tasks mmlu,gsm8k

FAQ

Questions

Can I run CUDA on a Mac?

Not locally: Apple silicon has no NVIDIA GPU, and CUDA needs one. gpushed gives your Mac a dedicated NVIDIA GPU in the cloud with CUDA 12.6 ready, one command away, so PyTorch, vLLM, Triton and your own kernels run from your Mac's terminal.

Which GPU should I pick for fine-tuning?

For LoRA or QLoRA on 7B–8B models, the L4 (24 GB) is the best value. Pick the A100 (40 GB) for 13B+ models, longer contexts, bigger batches, or full fine-tuning of smaller models. See choosing a GPU.

Can I use Jupyter or VS Code?

Yes. Connect with plain SSH using the key in ~/.gpushed/state/box_ssh_key (the IP is in gpushed status) and forward a port for Jupyter, or add the box as a host in VS Code Remote-SSH.

Why Mac only?

gpushed's client runs inside Apple's native container runtime, which needs a Mac with Apple silicon on macOS 26 or later. Focusing on one platform keeps setup to a single command.

What do I need to install?

Just gpushed. Its setup downloads Apple's container runtime from Apple's GitHub releases, checks Apple's signature and installs it, asking for your password once. No Terraform, gcloud, Python or GPU drivers on your Mac.

What's on the box?

Ubuntu 22.04 with the NVIDIA driver and CUDA Toolkit 12.6, plus Python 3.11 (pip and uv), Node.js 24 LTS, Rust, git and build tools. pip install torch and go, with full root access for anything else.

Where does it run?

On Google Cloud, in the region nearest you: Iowa, South Carolina or Oregon in the US, the Netherlands, or Singapore. If it's out of GPUs, gpushed tries its other zones and then the next nearest region automatically. Pick one yourself with gpushed up --region europe-west4. Prices differ a little by region; gpushed plans shows yours.

What happens when my credit runs out?

You get an email when your balance drops to $2. Just before it reaches zero your box is stopped, with its disk kept. Top up and run gpushed start to resume. A box that stays unfunded for 24 hours is deleted.

Can I keep my data between sessions?

Yes. gpushed stop pauses the GPU and keeps the disk for about $0.03/hour; gpushed start brings it back. gpushed down deletes the box and its disk for good. A box whose GPU sits idle, with nothing running on it and nobody connected, for 5 minutes stops itself, so a forgotten box doesn't run up a bill.

How is it billed?

Per second, from your prepaid balance, from the moment the box exists until it's deleted. gpushed history shows every charge and top-up.

Can I run more than one box?

One box per account for now. Delete it with gpushed down to switch plans.
